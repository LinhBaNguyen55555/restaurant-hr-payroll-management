# Animation references and dependencies

This application uses GSAP, @gsap/react, Motion and @animate-ui/react as package dependencies. Their licenses remain in their respective packages. The restaurant illustration is original CSS geometry; no external image or model is required.

Implementation guidance was read from:

- https://github.com/greensock/gsap-skills — React lifecycle, scoped selectors, context-safe handlers, quickTo and reduced-motion handling.
- https://github.com/imskyleen/animate-ui — Base UI dialog primitives, shared motion tokens and reduced-motion configuration.

Animate UI is copyright 2025 Elliot Sutton under MIT with a Commons Clause condition: application use is permitted; redistribution or sale of the components themselves in their original form is restricted. No component library is redistributed here; the app imports the installed package.

The complete license notices are retained in `frontend/notices`. The reference checkouts are ignored and are not application runtime dependencies.
